# Bone Denim Shop

Webshop-concept voor Bone Denim (Atlanta). Statische site: `index.html` + `assets/`.

## Online zetten met GitHub Pages
1. Upload alle bestanden van deze map naar een nieuwe repository.
2. Ga naar **Settings → Pages**.
3. Kies bij *Source*: **Deploy from a branch**, branch **main**, map **/ (root)** en klik **Save**.
4. Na een minuutje staat de site op `https://<gebruikersnaam>.github.io/bone-denim-shop/`.
